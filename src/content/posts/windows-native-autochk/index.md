大家是否还记得这样一个画面：在那个使用 Windows XP 或 Windows 7 的年代，每当我们遇到意外断电或是强行长按电源键关机，再次开机时，原本熟悉的滚动条过后，迎来的不是桌面，而是一个纯蓝底色（或纯黑底色）的界面。屏幕上飞速跳动着一排排白色的英文字符，上面还赫然写着“按任意键跳过磁盘检查”……

对于很多不熟悉电脑的人来说，这个无法用鼠标操作、满屏代码的界面简直就是“童年阴影”，看着就像是电脑彻底坏掉了。

但作为一个技术探客，你是否思考过：这个界面究竟是什么？它运行在操作系统的哪一个阶段？既然它能在进入桌面之前显示文字，那么我们能不能自己写一段代码，把我们的专属程序塞进这个神秘的阶段呢？

今天，月半菌就带你彻底扒下它的底裤，跨越二十年的技术演进，亲手用 C 语言“裸编”一个底层原生程序，劫持 Windows 的启动过程！
